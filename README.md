# Sistema Adaptativo para la Práctica de Álgebra

## Descripción

Sistema web desarrollado como Trabajo Final de Grado de la Licenciatura en Informática.

Su objetivo es proporcionar práctica progresiva de álgebra mediante la identificación de patrones de error, la generación de ejercicios y la aplicación de actividades de refuerzo.

## Tecnologías utilizadas

- Python 3
- Django 5
- MySQL
- HTML y CSS
- Git y GitHub

## Funcionalidades de la primera versión

- Registro e inicio de sesión de estudiantes.
- Acceso mediante código de grupo.
- Explicaciones matemáticas.
- Generación de ejercicios.
- Corrección de respuestas.
- Identificación de determinados errores.
- Activación de actividades de refuerzo.
- Avance progresivo por dificultades.
- Obtención de medallas por respuestas correctas.

## Estado del proyecto

Primera versión funcional en desarrollo.

Actualmente se encuentran implementadas parcialmente las actividades del Nivel 5, correspondientes a jerarquía de operaciones y operaciones combinadas con números enteros.

Se continuará incorporando contenido matemático, reglas de identificación de errores, estadísticas y funcionalidades docentes.
